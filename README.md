## 📖 Описание

**Autogenesia** — это интеллектуальный CLI-ассистент, который не просто пишет код, а ведет полноценную разработку: анализирует кодовую базу, планирует архитектуру, генерирует изменения, тестирует их и применяет только после вашей проверки.

Система поддерживает работу с **Python, JavaScript/TypeScript, Java и Go**, автоматически управляя зависимостями и форматированием для каждого языка.

### ✨ Ключевые возможности

- 🧠 **Мультиагентность:** Оркестратор, Пре-фильтр, Генератор, Валидатор и Тестировщик работают в связке.
- 🌐 **Мульти-провайдерность:** Работает через OpenAI SDK. Поддержка OpenRouter, Deepseek API, GLM Coding Plan, Qwen Cloud и OpenCode Go.
- 🗺️ **Интеллектуальный Пре-фильтр:** Полноценный агент с возможностью планирования архитектуры до написания кода.
- 🧪 **Автотестирование:** В конце пайплайна есть возможность вызвать Агента-Тестировщика, который проверяет код и пишет отчет.
- 🧩 **Кастомные советы (Advice):** Вы можете создавать свои правила для ИИ в JSON-файлах.
- 💾 **Виртуальная ФС:** Безопасное применение изменений с возможностью отката (бэкапы).

## 🚀 Установка

Для работы системы необходимо, чтобы в вашем `PATH` были доступны следующие инструменты, так как система использует их для парсинга, линтинга и компиляции разных языков:

<details>
<summary><strong>⚙️ Системные требования (нажмите для раскрытия)</strong></summary>

Помимо **Python 3.11+**, убедитесь, что установлены:
1. **Node.js** (включает `npm`) — для работы с JavaScript/TypeScript.
2. **Go** — для работы с `.go` файлами.
3. **Java JDK** и **Maven** — для работы с Java-проектами.

Система (`dependency_manager.py`) также попытается автоматически установить следующие утилиты форматирования, если их нет:
- **Python:** `black`, `autopep8`, `isort`, `yapf`, `ruff`
- **JS/TS:** `eslint`, `prettier`, `typescript`

</details>

## 💡 Как пользоваться

### Режимы работы

1. **🤖 Режим Агента (Agent Mode):** Основной режим. Вы формулируете задачу — система сама пишет, проверяет и предлагает применить код.
2. **💬 Режим Вопросов (Ask Mode):** Анализ кода, поиск багов и рекомендации без изменения файлов.
3. **💡 Общий Чат (General Chat):** Универсальный помощник без привязки к коду (с подрежимом Legal).

### Как правильно делать запросы в режиме Агента

Запросы должны быть четкими. Вот примеры:

<details>
<summary><strong>📝 Примеры запросов</strong></summary>

```text
# Планирование (если включен продвинутый пре-фильтр)
"Спроектируй архитектуру модуля аутентификации и напиши план."

# Генерация кода (Python)
"Добавь метод в класс IndexManager для очистки старых индексов. Метод должен принимать путь к директории."

# Генерация кода (JS/TS)
"Создай новый компонент React 'UserCard', который принимает пропсы: name, email и avatarUrl. Используй TypeScript."

# Рефакторинг (Java)
"Отрефактори класс PaymentService, вынеси логику валидации карты в отдельный класс CardValidator."

# Использование советов
"Напиши парсер для XML. Используй совет custom_xml_parsing_rules"
```
</details>

### 🧠 Кастомные советы (Advice Catalog)

Система позволяет вам "обучать" ИИ специфичным правилам вашего проекта:
1. Откройте `app/advice/advice_catalog.json` и добавьте краткое описание совета (например, `"my_api_rules": "Использовать только asyncio для запросов"`).
2. В `app/advice/advice_content.json` подробно опишите правило.
3. В запросе к ИИ просто упомяните: *"Сделай по совету my_api_rules"*.
ИИ вызовет инструмент `get_advice`, прочитает ваши инструкции и применит их.

## 🏗️ Архитектура

Пайплайн обработки запроса состоит из нескольких этапов:

1. **Пре-фильтр (Pre-filter Agent):** Анализирует запрос. В *продвинутом режиме* составляет план архитектуры и сохраняет его в `.ai-agent/current_plan.md`.
2. **Оркестратор (Orchestrator):** Анализирует код с помощью инструментов, пишет инструкцию для Генератора.
3. **Генератор (Code Generator):** Пишет код для Python, JS/TS, Java или Go.
4. **Валидатор (Validator):** Проверяет синтаксис, импорты, типы и запускает код (Runtime check).
5. **Тестировщик (Tester Agent):** Появился в новой версии! Запускается в конце, пишет тесты, выполняет их и выдает красивый Markdown-отчет.

## 🛠️ Инструменты Агента

Оркестратор имеет доступ к **12+ инструментам** для анализа кода.

<details>
<summary><strong>🔍 Список доступных инструментов</strong></summary>

#### Чтение и анализ
- `read_file` — чтение файла целиком.
- `read_code_chunk` — чтение конкретной функции/класса (экономит токены).
- `search_code` — семантический поиск по индексу.
- `grep_search` — поиск по регулярным выражениям.

#### Поиск информации
- `web_search` — поиск в интернете (DuckDuckGo).
- `show_file_relations` — анализ зависимостей файла.

#### Тестирование и зависимости
- `run_project_tests` — запуск pytest.
- `list_installed_packages` — список установленных пакетов (pip, npm, go, maven).
- `install_dependency` — умная установка пакетов (понимает, что `docx` это `python-docx`, может ставить `npm` и `go get`).

#### Экспертные знания
- `get_advice` — доступ к вашей базе знаний (`advice_content.json`).

</details>
